# Property Accessor

필드에 어트리뷰트를 적용하여 프로퍼티를 자동으로 생성하는 C# 소스 제네레이터입니다.

## 빌드하기

다음과 같은 순서로 명령을 수행하여 NuGet 패키지를 생성할 수 있습니다.

```shell
dotnet build -c Release
dotnet pack ./PropertyAccessor/PropertyAccessor.csproj -c Release
```

`./PropertyAccessor/bin/Release/` 폴더에 `nupkg` 확장자를 가지는 패키지가 생성됩니다.

## 사용법

프로퍼티를 생성할 타입과 이를 감싸는 모든 타입에는 `partial` 한정자를 추가해야 합니다. 필드에 `Get` 또는 `GetSet` 어트리뷰트를 적용하여 프로퍼티를 생성할 수 있습니다. 타입 안에서 공통으로 사용할 접근 한정자와 이름 규칙은 `PropertyGenerationDefaults` 어트리뷰트로 지정할 수 있습니다.

### Get, GetSet 어트리뷰트를 사용하기

`static`이 아닌 필드에 `Get`과 `GetSet` 어트리뷰트를 적용함으로써 프로퍼티를 추가할 수 있습니다. `Get`과 `GetSet`은 동시에 선언할 수 없습니다.

```csharp
using Macaron.PropertyAccessor;

public partial class Foo
{
    [Get]
    private int _bar;
    
    [GetSet]
    private int _baz;
    
    // readonly 필드에 GetSet을 선언하면 set 대신 init을 사용합니다.
    [GetSet]
    private readonly int _qux;
}
```

위 코드는 다음과 같은 코드를 자동으로 생성합니다.

```csharp
// <auto-generated />
#nullable enable

partial class Foo
{
    public int Bar
    {
        get => _bar;
    }

    public int Baz
    {
        get => _baz;
        set => _baz = value;
    }

    public int Qux
    {
        get => _qux;
        init => _qux = value;
    }
}
```

기본적으로 필드 이름의 접두어가 `_` 혹은 `m_`인 경우 이를 제거하고 파스칼 케이스로 변경한 것을 프로퍼티 이름으로 사용합니다.

#### Get 프로퍼티 타입 지정하기

`Get`의 `Type` 프로퍼티에 생성할 프로퍼티의 타입을 직접 지정할 수 있습니다.

```csharp
using Macaron.PropertyAccessor;

public partial class Foo
{
    [Get(Type = typeof(int))]
    private long _answer;
}
```

위 코드는 다음과 같은 코드를 생성합니다.

```csharp
// <auto-generated />
#nullable enable

partial class Foo
{
    public int Answer
    {
        get => (int)_answer;
    }
}
```

타입의 유효성은 C# 컴파일러의 변환 규칙에 따라 검사합니다. 따라서 상속과 인터페이스 구현뿐 아니라 숫자 변환, 박싱과 언박싱, 명시적 참조 변환, 사용자 정의 변환도 사용할 수 있습니다.

- 필드 타입에서 프로퍼티 타입으로 변환할 수 있어야 합니다.
- 암시적 변환이 아닌 경우 생성된 접근자에 명시적 캐스트를 추가합니다.

명시적 참조 변환이나 언박싱처럼 컴파일은 가능하지만 실제 값에 따라 실패할 수 있는 변환은 프로퍼티 접근 중 `InvalidCastException`을 발생시킬 수 있습니다.

#### setter를 별도의 메서드로 생성하기

`GetSet`의 `setterName` 생성자 인수에 메서드 이름을 지정하면 프로퍼티는 getter만 생성하고 지정한 이름으로 필드에 값을 대입하는 별도의 메서드를 생성합니다. 메서드는 프로퍼티와 같은 접근 한정자를 사용합니다. `setterName`을 생략하거나 빈 문자열로 두면 기존처럼 `set` 접근자를 생성합니다.

```csharp
using Macaron.PropertyAccessor;

public partial class Foo
{
    [GetSet(setterName: "SetValue")]
    private int _value;
}
```

위 코드는 다음과 같은 코드를 생성합니다.

```csharp
// <auto-generated />
#nullable enable

partial class Foo
{
    public int Value
    {
        get => _value;
    }

    public void SetValue(int value) => this._value = value;
}
```

`readonly` 필드에는 사용할 수 없고 기존 멤버나 생성되는 멤버와 이름이 동일하면 안 됩니다. 매개변수 타입이 다른 메서드 오버로드는 가능합니다.

### 상속 프로퍼티 자동 override

생성할 프로퍼티와 이름·타입이 같은 `abstract`, `abstract override` 인스턴스 프로퍼티가 상속 계층에 존재한다면 `override`를 추가합니다.

```csharp
using Macaron.PropertyAccessor;

public abstract class CounterBase
{
    public abstract int Count { get; set; }
}

public partial class Counter : CounterBase
{
    [GetSet]
    private int _count;
}
```

위 코드는 다음과 같은 코드를 생성합니다.

```csharp
public override int Count
{
    get => _count;
    set => _count = value;
}
```

프로퍼티와 각 접근자의 접근 제한자, `get`·`set`·`init` 구성이 모두 일치해야 합니다. 예를 들어 기반 프로퍼티가 `get; set;`이면 `[Get]`은 사용할 수 없고, `get; init;`이면 readonly 필드의 `[GetSet]`이 필요합니다. 기존 설정을 기반 프로퍼티에 맞춰 자동으로 변경하지 않습니다.

### PropertyGenerationDefaults 옵션

`PropertyGenerationDefaults`는 타입 또는 어셈블리에서 생성되는 프로퍼티의 기본 옵션을 지정합니다.

- `PropertyAccessModifier AccessModifier`는 생성할 프로퍼티의 접근 한정자를 지정합니다.
- `string? PrefixPattern`은 필드 이름에서 제거할 접두어를 정규식으로 지정합니다.
- `PropertyNamingRule NamingRule`은 접두어 제거 후 프로퍼티 이름에 적용할 대소문자 규칙을 지정합니다.

#### 타입 기본값

타입 선언에 어트리뷰트를 붙여 해당 타입과 그 안에 선언된 중첩 타입의 기본 옵션을 지정합니다.

```csharp
using Macaron.PropertyAccessor;

[PropertyGenerationDefaults(
    AccessModifier = PropertyAccessModifier.Public,
    PrefixPattern = "f",
    NamingRule = PropertyNamingRule.CamelCase
)]
public partial class Foo
{
    [Get]
    private string fName;

    public partial class Bar
    {
        [Get]
        public int fAge;
    }
}
```

생성되는 프로퍼티는 다음과 같습니다.

```csharp
partial class Foo
{
    public string name
    {
        get => fName;
    }

    partial class Bar
    {
        public int age
        {
            get => fAge;
        }
    }
}
```

#### 어셈블리 기본값

어셈블리의 `AssemblyInfo.cs` 같은 C# 소스 파일에 다음과 같이 한 번 선언합니다. Unity에서는 적용할 `.asmdef` 어셈블리에서 컴파일되는 소스 파일에 선언합니다.

```csharp
using Macaron.PropertyAccessor;

[assembly: PropertyGenerationDefaults(AccessModifier = PropertyAccessModifier.Internal)]
```

#### 프로젝트 기본값

전역 AnalyzerConfig 파일에 접근 한정자, 접두어 정규식, 이름 규칙의 프로젝트 기본값을 지정할 수 있습니다.

```text
is_global = true

macaron_property_accessor.access_modifier = Internal
macaron_property_accessor.prefix_pattern = ^(m_|_)
macaron_property_accessor.naming_rule = PascalCase
```

- .NET 프로젝트에서는 프로젝트 디렉터리에 `.globalconfig`를 둡니다. 여러 프로젝트에서 공유하려면 공통 상위 디렉터리에 두면 됩니다. 다른 이름으로 저장한 파일은 프로젝트의 `GlobalAnalyzerConfigFiles` 항목에 추가합니다. [전역 AnalyzerConfig 설정](https://learn.microsoft.com/dotnet/fundamentals/code-analysis/configuration-files#global-analyzerconfig)
- Unity 프로젝트에서는 `Assets/Default.globalconfig`에 같은 내용을 넣습니다. Unity는 기본 스크립트 어셈블리와 `.asmdef` 어셈블리의 컴파일에 이 파일을 전달합니다. 어셈블리 전용 `.globalconfig`가 있으면 Unity는 그 파일을 대신 사용하므로, 해당 어셈블리에도 필요한 공통 옵션을 전용 파일에 포함합니다. [Unity AnalyzerConfigPath 문서](https://docs.unity3d.com/6000.0/Documentation/ScriptReference/Compilation.ScriptCompilerOptions.AnalyzerConfigPath.html)

#### 필드별 이름과 접근 한정자 지정하기

필드별 프로퍼티 이름은 `Get` 또는 `GetSet`의 `name` 생성자 인수로, 접근 한정자는 `AccessModifier` 프로퍼티로 지정할 수 있습니다.

```csharp
using Macaron.PropertyAccessor;

[PropertyGenerationDefaults(AccessModifier = PropertyAccessModifier.Protected)]
public partial class Foo
{
    [Get(name: "name")]
    private string fName;

    [GetSet("Age", AccessModifier = PropertyAccessModifier.Private)]
    private int fAge;
}
```

위 코드는 다음과 같은 코드를 생성합니다.

```csharp
// <auto-generated />
#nullable enable

partial class Foo
{
    protected string name
    {
        get => fName;
    }

    private int Age
    {
        get => fAge;
        set => fAge = value;
    }
}
```

#### 옵션 적용 순서

각 옵션은 **필드 → 현재 타입 → 가까운 바깥 타입 → 어셈블리 → 프로젝트 설정 → 라이브러리 기본값** 순으로 찾습니다. 앞선 범위에서 옵션을 생략하면 다음 범위의 값을 사용합니다.

라이브러리 기본값은 `Public`, 접두어 정규식 `^(_|m_)`, `PascalCase`입니다. 어트리뷰트에서 `PrefixPattern = null`을 명시하면 이 기본 정규식을 사용하고, `PrefixPattern = ""`을 지정하면 접두어 제거를 생략합니다. 접근 한정자와 이름 규칙을 라이브러리 기본값으로 되돌리려면 `AccessModifier = PropertyAccessModifier.Public`과 `NamingRule = PropertyNamingRule.PascalCase`를 각각 지정합니다.
